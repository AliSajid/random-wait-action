## Built for one narrow problem

<CardGrid>
    <Card title="Stagger matrix jobs" icon="rocket">
        Prevent every matrix job from reaching the same external service at the
        same instant.
    </Card>
    <Card title="Reduce synchronized bursts" icon="warning">
        Spread individually reasonable requests over a configurable interval.
    </Card>
    <Card title="Introduce timing variation" icon="puzzle">
        Exercise workflows that should not depend on an exact order of
        completion.
    </Card>
</CardGrid>

:::note[Deliberately small]
Randomized jitter is not a replacement for retries, exponential backoff, concurrency controls, or provider-specific rate-limit handling. It solves the narrower problem of unnecessary synchronization.
:::

## Small action, maintained like infrastructure

<div class="trust-row">
    <span>Node 24 runtime</span>
    <span>No network requests</span>

    <span>Validated inputs</span>
    <span>CodeQL</span>
    <span>OpenSSF practices</span>

The action has no required inputs. By default, it waits between **1 and 10 seconds**. You can configure both bounds up to **120 seconds**, and read the selected delay from the `wait_time` output.
